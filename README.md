# МП.Штаб

Веб-версия: https://dmanaseev-crypto.github.io/mp.lnr/

Интерактивный MVP цифровой экосистемы Молодёжного парламента при Народном Совете ЛНР. Проект рассчитан на Windows 10/11 и использует Tauri 2 + React + TypeScript.

## Что реализовано

- главная панель председателя и персональная панель участника;
- обезличенный демонстрационный вход, локальная регистрация участников, выход и выбор учётной записи;
- тёмная и светлая темы интерфейса;
- создание поручения с исполнителем, муниципалитетом, проектом, дедлайном и критериями;
- полный цикл задачи: новая → принята → в работе → на проверке → выполнена;
- возврат на доработку, принятие результата и начисление XP;
- канбан с перетаскиванием карточек;
- дедлайны, просрочка, уведомления и глобальный поиск;
- разграничение ролей председателя и участника;
- экраны коммуникации, команд, проектов, календаря, развития, достижений, аналитики, профиля и управления;
- банк молодёжных инициатив: создание идеи, муниципалитет и направление, поддержка голосом, фильтры и перевод по этапам;
- адаптивный тёмный интерфейс без внешних веб-ресурсов;
- локальное сохранение состояния задач в `localStorage`.
- локальное сохранение инициатив и голосов в `localStorage`.

## Онлайн-версия

Сайт публикуется через GitHub Pages автоматически после каждого push в ветку `main`.
Откройте ссылку выше и поделитесь ей с участниками. Данные текущей MVP-версии, включая самостоятельно зарегистрированные аккаунты, сохраняются локально в браузере каждого пользователя. Общая регистрация на разных устройствах и приглашения требуют подключения серверной базы данных.

## Демонстрационный сценарий

1. На экране входа выберите обезличенную учётную запись и введите первичный пароль `parliament2026`.
2. Войдите как председатель, создайте поручение и назначьте его участнику.
3. Выйдите и войдите под учётной записью назначенного участника.
4. Откройте задачу и последовательно нажмите `Принять задачу`, `Начать работу`, `На проверку`.
5. Снова войдите как председатель и выберите `Принято` или `Нужна доработка`.
6. Пароль выбранной учётной записи можно изменить в разделе `Профиль`.
7. На вкладке `Регистрация` можно создать локальный аккаунт участника и сразу войти в систему.

## Запуск

Потребуются Node.js 20+, Rust stable и системные зависимости Tauri для Windows.

```powershell
npm install
npm run dev
```

Запуск в настольной оболочке:

```powershell
npm run tauri dev
```

Сборка установщика:

```powershell
npm run tauri build
```

## Готовая Windows-сборка

- Standalone-файл без установки: `release/МП.Штаб-Standalone.exe`.
- NSIS-установщик: `release/МП.Штаб_0.1.0_x64-setup.exe`.
- Portable-приложение: `release/portable/МП.Штаб.exe`.
- Для portable-версии файл `WebView2Loader.dll` должен находиться рядом с приложением, как в каталоге `release/portable`.

## Ограничение MVP

Текущий слой данных демонстрационный, обезличенный и локальный. Общая регистрация по приглашениям, серверная авторизация, база данных, защищённое файловое хранилище и журнал аудита должны быть реализованы до эксплуатации с реальными пользователями.
